# Hemanth Kumar M J — Portfolio

A static portfolio covering security engineering, independent research, responsible disclosure, and investigation tools.

## Files

- `index.html`: the current portfolio, including CSS and JavaScript.
- `assets/`: images referenced by the portfolio and its galleries.
- `.nojekyll`: serves the static site without Jekyll processing.
- `.gitignore`: excludes local working files, archives, and résumé backups.

No dependency installation or build step is required. Open `index.html` in a browser for local preview.

## Publish with GitHub Pages

1. Create a GitHub repository. Use `hkmj19.github.io` for the account's root site, or a name such as `portfolio` for a project site.
2. Push the **contents of this folder** to the repository's `main` branch. Keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, then **main** and **/ (root)**, and save.
5. Use the site URL shown by GitHub after deployment completes.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
